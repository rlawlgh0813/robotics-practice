# Class 01

## Digital Twin / USD / Factory Environment

Isaac Sim 학습의 시작으로 digital twin의 목적과 USD 기반 scene 표현을 학습했습니다. 로봇과 공정 설비를 가상 환경에 배치해 실제 작업을 검증할 수 있는 기반 개념을 정리했습니다.

## Main Topics

- digital twin을 이용한 로봇 공정 검증 흐름
- USD stage, prim, transform, asset reference의 역할
- Isaac Sim에서 공정 환경을 구성하는 방법
- Gazebo 기반 simulation 학습과 Isaac Sim의 확장 지점

## Learned

- 로봇 단일 모델이 아니라 설비와 센서까지 포함한 scene 단위로 시스템을 바라보는 방법
- 향후 manipulation task와 sensor simulation을 같은 환경에서 검증할 수 있다는 점
