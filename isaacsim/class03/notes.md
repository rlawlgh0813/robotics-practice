# Class 03

## Python Scripting API

Isaac Sim scene과 robot 동작을 Python으로 생성하고 제어하는 기초 예제를 실습했습니다. 제공 코드의 단계별 예제는 `scripting_examples/`에 정리했습니다.

## Code Examples

| Example | Practice |
| --- | --- |
| `슬라이드14/test_script.py` | USD stage에 Xform과 Sphere prim 생성 |
| `슬라이드41/hello_world.py` | 기본 scene/ground 구성 |
| `슬라이드48/hello_world.py` | robot asset을 stage에 reference로 추가 |
| `슬라이드51/hello_world.py` | Jetbot articulation action 적용 |

## Learned

- Python API로 prim과 scene을 생성하는 방법

- 반복 가능한 simulation experiment를 script로 구성하는 기초
